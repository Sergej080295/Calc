# Методика расчета времени (проф. версия)

## Стандартная структура расчета
Для операций резания используется типовой технологический расчет:
- `n = 1000 * Vc / (π * D)`
- `Vf = f * n`
- `Tмаш = L / Vf`

Общее время партии:
- `Tпартии = Tналадки + Tшт * Qty`
- `Tна_1_дет = Tшт + Tналадки / Qty`

## Что можно подстроить под конкретный цех
В интерфейсе вынесен отдельный **«Паспорт норм»**:
- коэффициент скорости резания,
- коэффициент ручных операций,
- отдельные наладки по ключевым операциям.

Это сделано специально, чтобы базовая модель была технологически корректной,
а фактическая цеховая точность доводилась без изменения кода.

## Принципы устойчивости
- Формулы непрерывные (без «ступенек» при малом изменении входа).
- Сводка есть по каждой операции отдельно + общая сводка по включенным операциям.
- Операции изолированы: выключение/правка одной не ломает остальные.

## Источники ориентиров (для базовых коэффициентов)

- Starrett — ориентиры по ленточнопильной резке.
- Материалы по vibratory finishing — принципы загрузки media:parts.
