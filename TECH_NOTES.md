# Методика расчета времени (кратко)

## 1) Базовые формулы машинного времени
Для сверления/зенковки/резьбы используется классическая схема:
- `n = 1000 * Vc / (π * D)`
- `Vf = f * n`
- `t = L / Vf`

Где `Vc` — скорость резания (м/мин), `D` — диаметр инструмента, `f` — подача на оборот, `L` — длина хода.

## 2) Принятые допущения для цехового расчета
Чтобы не перегружать пользователя вводом, оставлены только параметры, которые реально меняют трудоемкость:
- количество отверстий,
- диаметры,
- глубина/толщина,
- способ зачистки,
- габариты/объем для галтовки,
- тип проката и сечение для лентопила,
- материал и размер партии.

Время партии считается как:
- `T_batch = T_setup + T_piece * Qty`
- `T_piece_total = T_piece + T_setup / Qty`

Это устраняет резкие скачки времени при небольших изменениях партии.

## 3) Источники коэффициентов и ориентиров
- Sandvik Coromant (Machining calculator / формулы RPM, feed, time).
- Viking Drill & Tool speed/feed charts (ориентиры по сверлению и метчикам).
- Starrett band saw recommendations (материалозависимость ленточного пиления).
- Finishing Technologies / виброобработка: правило загрузки `3:1` media:parts и оценка загрузки чаши.

## 4) Калибровка зенковки по фактическим данным
Ваш набор фактов использован как эмпирическая калибровка «ручной» составляющей времени на отверстие
(позиционирование, съём/установка, контроль, колебания квалификации).

Поскольку разброс высокий, принята устойчивая модель:
- машинная часть (геометрия + режим),
- плюс плавная «ручная» часть на отверстие,
- плюс мягкие коэффициенты на угол 120°/диаметр/большое число отверстий.

Это дает более стабильный и предсказуемый результат без ступенек.
