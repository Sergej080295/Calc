# Методика расчета времени (проф. версия v4)

## 1) Стандарт расчета по операциям
Каждая операция раскладывается на три составляющие:
1. `Tmach` — машинное время (по RPM/Feed/Stroke),
2. `Taux` — вспомогательное/ручное время,
3. `Tsetup` — наладка.

Финальная формула:
- `Tbatch = Tsetup + (Tmach + Taux) * Qty`
- `Tpiece = (Tmach + Taux) + Tsetup / Qty`

## 2) Базовые формулы резания
- `n = 1000 * Vc / (π * D)`
- `Vf = f * n`
- `Tmach = L / Vf`

Эти формулы применяются в сверловке, резьбе, зенковке и лентопиле (через площадь сечения / удельную производительность).

## 3) Настройка под конкретное производство
Чтобы вы могли быстро «приземлить» модель на свой цех, добавлен блок
**«Паспорт норм»**:
- коэффициенты скорости и ручной составляющей,
- наладки по операциям,
- базовая производительность лентопила по алюминию.

## 4) Стабильность модели
- Зависимости непрерывные, без ступеней при небольших изменениях входа.
- Каждая операция считается независимой функцией.
- Общая сводка агрегируется централизованно, поэтому изменения в одной операции не ломают другие.
